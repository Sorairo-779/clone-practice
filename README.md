# clone-practice

一個用於練習 Git 分支操作與 GitHub PR 協作流程的沙盒倉庫。

## 目的

- 練習分支建立、合併、衝突解決
- 練習 PR 工作流程（建立、review、merge）
- 練習倉庫規範化（README / LICENSE / .github）

## 快速開始

```bash
git clone git@github.com:sorairo-779/clone-practice.git
cd clone-practice
cat README.md
```

## 內容

- `docs/usage.md`：使用說明
- `.github/`：Issue 與 PR 範本
- `LICENSE`：MIT 協議

## 貢獻

歡迎提 PR。建議先開 Issue 討論方向。
